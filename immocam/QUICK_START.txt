📌 ENDPOINTS PRINCIPAUX POUR TESTER
═══════════════════════════════════════════════════════════════════════════════════

PUBLIC (aucune authentification):
  GET  /annonces                    → Liste des annonces
  GET  /annonces/{id}               → Détail d'une annonce
  GET  /types-biens                 → Types de bien
  GET  /localisations               → Villes et quartiers

AUTHENTIFICATION:
  POST /auth/login                  → Connexion
  POST /auth/refresh                → Rafraîchir token
  POST /auth/register               → Inscription
  POST /auth/verify-email           → Validation email

PRIVÉ (authentification requise):
  GET  /annonces/mes-annonces       → Mes annonces
  POST /annonces                    → Publier annonce
  PUT  /annonces/{id}               → Modifier annonce
  GET  /profil                      → Mon profil


💻 EXEMPLE DE REQUÊTE (curl)
═══════════════════════════════════════════════════════════════════════════════════

1. Récupérer les annonces:
   curl http://localhost:8080/annonces?page=0&taille=10

2. Se connecter:
   curl -X POST http://localhost:8080/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email":"jean@email.com","motDePasse":"User123"}'

3. Récupérer mes annonces (avec token):
   curl -H "Authorization: Bearer YOUR_TOKEN" \
     http://localhost:8080/annonces/mes-annonces

4. Voir détail annonce:
   curl http://localhost:8080/annonces/1
